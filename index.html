Modelos utilizados

🟦 Modelo escolar — coeficiente constante

O coeficiente utilizado é o coeficiente linear calculado para a temperatura de referência de 25 °C.

L(T) = Lᵢ [1 + α₂₅ (T − Tᵢ)]

Neste modelo, α₂₅ permanece constante durante toda a variação de temperatura.

🟩 Modelo real — Papadakis (1972)

O comprimento é obtido diretamente a partir da função quadrática de dilatação de Papadakis.

F(T) = 1 + B₀×10⁻³ + B₁×10⁻⁶T + B₂×10⁻⁹T²
L(T) = Lᵢ · F(T) / F(Tᵢ)
